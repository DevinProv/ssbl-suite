Enable OBS WebSocket & get the password
  1. In OBS, open Tools → WebSocket Server Settings. (Built in to OBS 28+; older versions need the obs-websocket plugin.)
  2. Tick Enable WebSocket server. Leave Server Port at 4455 unless you've changed it.
  3. Keep Enable Authentication on, then click Show Connect Info (or Generate Password) to reveal the password.
  4. Copy the password into the field above. Use localhost as the host if OBS is on this same PC.
  5. Click Apply / OK in OBS, then hit Connect here.
